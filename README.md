# Aptlantis-Crystal

A dark SiYuan theme with #0E1520 backgrounds, #25F7F9 primary accents, and #FEFEFE text, derived from the supplied Crystal palette.

Original artwork and pipeline outputs are retained in the collection's `crystal-refs/` folder. The palette and swatch above are copies of those supplied outputs. Pipeline reports describe their original generation run; they do not establish current runtime acceptance.

## Installation and compatibility

Install the contents of `package/` into the theme directory named `apt-crystal` in your SiYuan workspace's appearance themes location, then select it in Appearance settings. Use the location documented for your installed SiYuan version. Restart SiYuan after replacing an installed theme before evaluating cached assets.

- Package version: `0.1.0`.
- Declared minimum SiYuan version: `3.7.0`.
- Declared modes: dark. Declared frontends: all.
- Source artwork is complete.
- Native SiYuan rendering and installation were not tested during this organization pass. Supplied screenshots are reference captures; their app version and capture procedure are not established here.
